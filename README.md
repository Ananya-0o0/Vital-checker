# Vital Signs Checker

A simple Python program that checks if heart rate, temperature and oxygen level are in a normal adult range.

**Educational only. Not medical advice. Ranges are general adult references.**

## How it works
- The user types heart rate, temperature and oxygen level
- Each value is compared with a reference range using if / elif / else

 Vital sign - Normal range used 
 Heart rate - 60 to 100 beats per minute 
 Temperature - 36.1 to 37.9 °C 
 Oxygen level - 95% or higher 

## Example
```
Heart rate (beats per minute): 72
Temperature (C): 36.8
Oxygen level (%): 98

Heart rate: normal
Temperature: normal
Oxygen: normal
```
